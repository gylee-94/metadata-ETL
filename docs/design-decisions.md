# 평가 도구의 설계 판단

## 조회 실패와 미수록을 분리한다

검색되지 않았다는 결과만으로 데이터베이스의 수록 여부를 알 수 없다. inventory를 선택 입력으로 받고, 미제공 시 미수록 판단을 유보한다. 불완전한 inventory의 사용은 로직만으로 검출할 수 없으므로 추출 절차도 기록해야 한다.

## 집합과 분모를 명시한다

반복 행은 식별자 집합으로 합쳐 집계한다. target이 비어 있으면 나눗셈 결과를 만들지 않고 오류로 처리한다. 질의 결과에 target 밖의 식별자가 있어도 그 자체로 오답이라고 판정하지 않는다.

## 원본과 파생 결과를 구분한다

스크립트는 입력을 수정하지 않고 JSON을 표준 출력으로 보낸다. 입력 파일 hash로 어떤 파일을 비교했는지 남긴다. 제3자 도구를 실행하지 않으므로 현재 테스트 성공은 MetaHQ 검증 성공을 뜻하지 않는다.
