# ETL 코드 학습 순서

## 첫 실습

집합 비교 도구의 출력을 먼저 예측하고 테스트를 실행한다. target과 retrieved만으로 왜 미수록 여부를 판정할 수 없는지 설명한다.

## 다음 실습

공개 또는 가상 레코드 10개를 사용해 읽기 → 정규화 → SQLite 저장을 별도로 구현한다. 각 단계의 입력·출력·실패·재실행 조건을 적는다.

- 서로 다른 식별자가 정규화 후 충돌하는 경우를 만든다.
- 같은 파일을 두 번 처리해도 레코드가 중복되지 않는지 확인한다.
- 쓰기 중 실패했을 때 부분 결과가 남는지 확인한다.
- 규칙을 바꾼 뒤 과거 결과와 새 결과를 구분할 수 있게 한다.

한 함수마다 예상 출력, 실제 출력, 차이의 원인, 반례를 기록한다. 코딩 도구를 사용하더라도 자료구조·예외 처리·저장 방식의 선택 이유는 직접 설명한다.
