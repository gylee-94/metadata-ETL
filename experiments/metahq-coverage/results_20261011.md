# MetaHQ 질환 조회와 배포본 수록 범위 확인

## 기록의 성격

검증 수행일은 **2026-10-11**, 공개 문서 정리일은 **2026-10-13**이다. 작성자가 당시 남긴 실행·비교 보고서를 바탕으로 공개 식별자와 집계 결과를 옮겼다. 새로 설치하거나 조회한 결과가 아니다.

원시 TSV, 전체 inventory, 실행 로그는 이 저장소에 포함하지 않는다. 따라서 공개된 식별자 목록의 교집합은 확인할 수 있지만, 원시 결과의 집계와 배포본 전체 미수록 판단을 이 저장소만으로 독립 재현할 수는 없다. 아래 전체 DB 확인 결과와 파일 해시는 당시 보고서에 기록된 값이다.

## 사용한 버전과 질의

| 항목 | 기록 |
|---|---|
| CLI / core | 1.2.0 / 1.2.0 |
| Python | 3.12.12 |
| 데이터 | [MetaHQ v1.2.0](https://zenodo.org/records/22715670), 2026-09-11 공개 |
| 압축 파일 크기 | 54,942,481 bytes |
| MD5 | `c01c177ab381ab74b7c4abdea55e877c` |
| SHA-256 | `1b30ee2e127069c137246ed9a7b6d54239e6f326f32c70f40bc7c4b75446a6d2` |

당시 배포 MD5와 다운로드 파일 크기의 일치를 확인했다. 질환명을 확인하고 MONDO 코드를 선택했다.

```bash
metahq search --query 'nonalcoholic fatty liver disease' --type disease --ontology MONDO
metahq retrieve diseases \
  --terms MONDO:0013209 \
  --level sample \
  --filters 'species=human,tech=rnaseq,ecode=any' \
  --mode annotate \
  --metadata 'series,platform,description' \
  --fmt tsv \
  --output runtime/results/nafld_human_rnaseq
```

## 미조회와 미수록을 나누어 확인

[사례 집합 5건](study_selection.md)은 위 7개 GSE와 겹치지 않았다. 당시 보고서는 질의 결과 외에 다음 계층도 확인했다.

| 확인한 계층 | 확인 규모 | 대상 5개 GSE |
|---|---:|---|
| 연구 메타데이터 | 27,128행 | 모두 발견되지 않음 |
| 연구 주석 | 27,128개 | 모두 발견되지 않음 |
| 샘플 주석의 `accession_ids.series` 연결 | 567,412개 주석 | 해당 GSE 연결 발견되지 않음 |

따라서 당시 사용한 배포본의 확인한 계층에서 이 5개 연구를 찾을 수 없었다. 최신 MetaHQ나 원 주석 제공 기관의 DB 전체에 없다는 결론은 아니다. 샘플의 Series 연결을 확인한 결과를 모든 GSM 식별자의 독립 대조로 확대하지 않는다.

`target.txt`와 `retrieved.txt`는 기존 보고서에서 옮긴 목록이다. 비교 스크립트로 **0/5 조회**를 다시 계산할 수 있다. 전체 inventory 파일이 없으므로 스크립트의 미수록 결과는 `null`로 남기며, 위 보고서의 미수록 결론과 별도로 취급한다.

## 해석과 한계

- 사례 5건에 대한 수록 범위 확인이다. GEO 전체 recall이나 추출 정확도를 측정하지 않았다.
- `annotate` 조회이므로 대조군 선정의 정확도나 분석용 코호트 구성의 타당성을 검증하지 않았다.
- 누락 원인은 확인하지 않았다. 배포일과 원 자원의 수집 마감일은 다를 수 있다.
- 이 결과만으로 다른 ETL의 우수성, 특정 아키텍처의 필요성이나 MetaHQ의 전반적인 성능을 주장할 수 없다.
- 얻은 설계 교훈은 **질의에서 나오지 않는 것과 배포본에 없는 것을 분리해 점검해야 한다**는 것이다.
